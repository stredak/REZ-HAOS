# REZ pro Home Assistant OS

Veřejný instalační repozitář aplikace REZ. Neobsahuje uživatelská data, dokumenty ani API klíče.

## Instalace

V Home Assistantu otevřete **Nastavení → Aplikace → Obchod s aplikacemi → Repozitáře** a přidejte:

`https://github.com/stredak/REZ-HAOS`

Potom nainstalujte aplikaci **REZ**.
